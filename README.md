## 1. Project Overview / Problem Statement & Approach

Banks and asset managers drown in unstructured text: news, filings and social posts that move markets
faster than people can read. SENTINEL is an AI/NLP Risk Engine that ingests that text in real time and turns
each item into three structured signals: a sentiment score (-1 to 1), an event class (Geopolitical,
Credit Event, Merger/Acquisition, ...) and an impact score (1 to 10).

Two downstream modules consume the signals. **Module A (Adaptive Index)** rebalances a 15-stock index from
the S&P 100 as sentiment changes. **Module B (Stress Lab)** runs event-driven stress tests on a synthetic
wholesale banking portfolio of loans, bonds and derivatives.

The signature feature is **PRECEDENT**: every live event is matched to similar historical events, and the
real market reaction after those events (measured from price history) calibrates the stress shocks, so they
are evidence-based and carry sample sizes and confidence bands instead of hand-picked numbers.

## 2. Architecture & Tech Stack

Data flow: sources -> connectors -> de-duplication -> Redis Streams -> NLP engine -> PRECEDENT ->
Module A / Module B -> FastAPI REST + WebSocket -> SENTINEL web terminal. Every automated action is
written to a hash-chained audit ledger. (Architecture diagram: `docs/architecture.png`, added at completion.)

- Backend: Python 3.11, FastAPI, asyncpg, Redis Streams, PostgreSQL 16 + pgvector
- ML (upcoming phases): PyTorch, Hugging Face Transformers (FinBERT-based), sentence-transformers, LightGBM, Captum
- Frontend: React + Tailwind (built with Lovable), consuming the API contract in the design doc

## 3. Dataset Used

All data is public or synthetic. No proprietary or client data is used.
- GDELT 2.0 GKG (news events), publisher RSS feeds, SEC EDGAR 8-K filings, Bluesky Jetstream and Reddit (social)
- Yahoo Finance (prices via yfinance) and FRED (rates, spreads, VIX)
- The wholesale banking portfolio is **synthetic**, generated by code from public datasets (labelled SYNTHETIC in the API)
- X/Twitter is not used live because it has no free read access; historical tweet datasets are used for training

Assumptions are documented as each phase lands (rating migration matrix, transaction-cost model, shock horizons).

## 4. Quickstart & Installation

Runtime: Python 3.11, PostgreSQL 16 + pgvector, Redis 7 (via Docker) on Linux/macOS/WSL.

```bash
git clone https://github.com/chaitenyachand/IGDTUW-Chaitenya-Chand-Hackathon.git
cd IGDTUW-Chaitenya-Chand-Hackathon
cp .env.example .env      # set SEC_USER_AGENT, FRED_API_KEY, Reddit keys
make up                   # db + redis + api + ingest
make seed                 # load the 15-stock universe
make check                # ping every data source
make prices && make fred  # market history and macro series
make test                 # unit tests
# API: http://localhost:8000/api/health
```
